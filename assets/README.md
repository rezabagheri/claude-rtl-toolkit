# Screenshots / assets

Drop the following images here (exact filenames), then they appear in the main README automatically.

| File | What to capture | Notes |
|------|-----------------|-------|
| `hero.png` | A Claude conversation rendered RTL — show the `⇒ RTL` chip above a message, Persian text in a nice font, and a code block staying LTR. | The most important shot; goes at the top. Landscape, ~1400px wide. |
| `settings.png` | The options page with the four sections (user / Claude / composer / code) and the line-height + line-numbers controls. | Light or dark — your choice. |
| `popup.png` | The toolbar popup (on/off, set-all, line numbers, language, health). | Small, native size is fine. |
| `code.png` *(optional)* | A code block with line numbers, ligatures (`->` `=>`), and a Persian comment staying LTR. | Nice "wow" detail shot. |

Tips:
- PNG for crisp UI; an animated **GIF** for `hero` is even better if you can record a quick toggle.
- Keep file sizes reasonable (< ~1 MB each) so the repo stays light.
- Avoid showing anything private in the conversation.
