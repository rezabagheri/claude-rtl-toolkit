# Claude RTL Toolkit

افزونه‌ی Chrome/Brave که به [claude.ai](https://claude.ai) پشتیبانی واقعی از راست‌به‌چپ (RTL) و کنترل تایپوگرافی برای هر بخش می‌دهد.

> چندزبانه: فارسی، عربی، عبری، اردو و انگلیسی — هم در تشخیص خودکار متن، هم در رابط کاربری.

---

## این چیه؟ (What)

افزونه‌ای روی نوار ابزار که در هر گفتگوی Claude به تو امکان می‌دهد:

**جهت**
- 🔄 **هر پیام** را جداگانه با یک چیپ بالای آن RTL/LTR کنی.
- 🔍 خط‌های RTL را **خودکار تشخیص** دهی (فارسی، عربی، عبری، سریانی، تانا، نکو، فرم‌های نمایشی).
- ⌨️ آخرین پیام را با `Alt+Shift+R` برگردانی؛ کادر تایپ هم خط‌به‌خط از متنِ تو پیروی می‌کند.
- 💾 انتخاب‌هایت بین رفرش‌ها و دستگاه‌ها بمانند (`chrome.storage.sync`).

**تایپوگرافی**
- 🔤 **فونت / اندازه / فاصله‌ی خطوط** مستقل برای پرسش‌های کاربر، پاسخ‌های Claude، کادر تایپ، و کدها.
- 📦 فونت‌های همراه: Vazirmatn و Estedad (فارسی)، Rubik (عبری + لاتین)، JetBrains Mono (کد، با ligature).

**کد**
- 💻 بلوک‌های کد حتی با کامنت RTL **همیشه چپ‌به‌راست** می‌مانند (`unicode-bidi: isolate`).
- 🔢 شماره خط انتخابی با هم‌ترازی دقیق.

**رابط**
- 🌍 رابط ۵ زبانه · 🎛️ popup (روشن/خاموش، همه‌RTL/LTR، شماره خط، زبان، نشانگر سلامت) · 📤 export/import · 🎨 تم خودکار.

## چرا وجود داره؟ (Why)

Claude در گفتگوهای چندزبانه عالیه — اما **رابطش** برای متن راست‌به‌چپ ساخته نشده:

- **متن RTL به‌طور پیش‌فرض چپ‌چین می‌شود.** چیزی به فارسی/عربی/عبری بپرس و پاسخ چپ‌به‌راست رندر می‌شود: نقطه‌گذاری سمت اشتباه می‌افتد، اعداد و پرانتزها جابه‌جا می‌شوند، و پاراگراف‌های بلند سخت‌خوان می‌شوند.
- **محتوای مخلوط بدترین حالت است.** پاسخ‌های واقعی، متن RTL را با اصطلاحات انگلیسی، کد inline و بلوک کد در هم می‌بافند. یک سوییچ RTL ساده‌ی کل‌صفحه، *کد را خراب می‌کند* و متن را هم نصفه‌نیمه درست می‌کند.
- **کنترل per-message وجود ندارد.** بعضی پیام‌ها انگلیسی‌اند، بعضی فارسی. یک toggle سراسری نمی‌تواند برای هر دو درست باشد — جهت باید **برای هر پیام** جدا باشد.
- **کنترل تایپوگرافی نیست.** فونت‌های پیش‌فرض خط‌های غیرلاتین را بد نمایش می‌دهند، با فاصله‌ی خطوطِ فشرده که خوانایی خط‌های متصل مثل فارسی و عربی را خراب می‌کند.
- **هیچ‌چیز ماندگار نیست.** حتی اگر راه‌حلی پیدا کنی، با هر رفرش از بین می‌رود.

**رویکرد:** درستش کن جایی که واقعاً مهم است — *برای هر پیام*، نه سراسری. جهت را از متن خودکار تشخیص بده ولی همیشه اجازه‌ی override دستی بده؛ **بلوک‌های کد را به هر قیمتی LTR نگه دار**؛ به هر نوع محتوا تایپوگرافی مستقل بده؛ و هر انتخاب را به خاطر بسپار. نتیجه طوری خوانده می‌شود که انگار Claude از اول برای RTL ساخته شده بود.

## چطور کار کنم؟ (How)

### نصب

1. این repo را clone کن (یا ZIP دانلود و extract کن).
2. آدرس `chrome://extensions` (یا `brave://extensions`) را باز کن.
3. **Developer mode** را از گوشه‌ی بالا فعال کن.
4. روی **Load unpacked** کلیک کن و پوشه‌ی `claude-rtl-toolkit` را انتخاب کن.
5. به `claude.ai` برو.

> پس از هر بار ویرایش فایل‌ها، روی کارت افزونه **🔄 reload** را بزن و تب را رفرش کن.

### استفاده‌ی روزمره

| کار | چطور |
|-----|------|
| جهت یک پیام | روی چیپ **`⇒ RTL` / `⇐ LTR`** بالای پیام کلیک کن |
| جهت آخرین پیام | `Alt+Shift+R` |
| جهت همه‌ی پیام‌ها یک‌جا | popup → «همه RTL» / «همه LTR» |
| فونت/اندازه/فاصله‌ی خطوط | popup → ⚙️ تنظیمات |
| روشن/خاموش کردن افزونه | popup → کلید بالا |

### تنظیمات

صفحه‌ی تنظیمات چهار بخش دارد — **پرسش‌های کاربر**، **پاسخ‌های Claude**، **کادر تایپ پیام**، و **کدها** (با toggle شماره خط). همه‌ی تغییرات **خودکار** ذخیره و **زنده** (بدون رفرش) اعمال می‌شوند.

### معماری

```
claude-rtl-toolkit/
├── manifest.json       # تعریف افزونه (MV3)
├── config.js           # مشترک: کلیدهای storage، دیکشنری i18n، لیست فونت‌ها، پیش‌فرض‌ها
├── content.js          # منطق اصلی: تشخیص پیام، جهت، فونت، شماره خط، میانبر
├── styles.css          # استایل‌های ثابت
├── popup.html/css/js   # منوی سریع روی آیکون
├── options.html/css/js # صفحه‌ی تنظیمات کامل
├── fonts/              # فونت‌های woff2 همراه
└── icons/
```

تصمیم‌های کلیدی طراحی:
- **storage-محور:** popup و options به همان کلیدهای `chrome.storage` می‌نویسند؛ `content.js` با `onChanged` واکنش می‌دهد.
- **CSS پویا:** تنظیمات فونت به یک `<style>` واحد ترجمه می‌شوند که با هر تغییر بازنویسی می‌شود.
- **ذخیره‌ی فقط override:** تنها انتخاب‌هایی که با تشخیص خودکار فرق دارند ذخیره می‌شوند.
- **تشخیص لایه‌ای و خود-ترمیم:** اگر DOM عوض شود، fallback محتوا-محور بازیابی می‌کند و health-check هشدار می‌دهد.
- **شناسه‌ی پایدار پیام:** از attribute پایدار یا hash قطعیِ متن (djb2)، نه مقدار تصادفی.

### فونت‌ها و مجوزها

همه متن‌باز (SIL OFL) و محلی همراه افزونه (به‌خاطر CSP سایت از CDN لود نمی‌شوند):

| فونت | کاربرد |
|------|--------|
| [Vazirmatn](https://github.com/rastikerdar/vazirmatn) | فارسی/عربی |
| [Estedad](https://github.com/aminabedi68/Estedad) | فارسی |
| [Rubik](https://fonts.google.com/specimen/Rubik) | عبری + لاتین |
| [JetBrains Mono](https://www.jetbrains.com/lp/mono/) | کد (ligature) |

### توسعه

- **افزودن زبان:** یک ورودی به `UI_LANGS` و یک بلوک به `I18N` (در `config.js`).
- **افزودن فونت:** فایل woff2 در `fonts/`، یک `@font-face` در `injectFont`، و یک گزینه در `FONT_OPTIONS`.
- **selectorها شکستند؟** همه در `SELECTORS` (در `content.js`) هستند؛ نشانگرِ popup موقع شکست عددِ **۰** نشان می‌دهد.
